# DevBin\n[![Build Status](https://img.shields.io/badge/Build-Unknown-red)](https://shields.io/) [![License](https://img.shields.io/badge/License-Unknown-red)](https://shields.io/) [![Version](https://img.shields.io/badge/Version-1.0.0-blue)](https://shields.io/)\n\nDevBin is a curated discovery site for the most trending and essential developer tools in the ecosystem, designed for developers to explore and utilize the latest tools to enhance their workflow. This project aims to provide a comprehensive platform for developers to discover, learn, and integrate new tools into their development process.\n\n## Features\n* Trending tool listings with detailed descriptions and usage examples\n* Search functionality for easy discovery of specific tools\n* User-friendly interface for exploring and learning about new tools\n* Integration with popular development frameworks and libraries\n* Community-driven feedback and review system for tools\n* Regular updates with new tool additions and existing tool updates\n\n## Tech stack\n| Layer | Technology |\n| --- | --- |\n| Frontend | React/TypeScript, Next.js |\n| Backend | Node.js/TypeScript |\n| Database | SQL, Prisma ORM |\n\n## Prerequisites\nTo run DevBin, you need to have Node.js and npm installed on your machine.\n\n## Getting started\n1. Clone the repository: ```bash\ngit clone https://github.com/thamarai-titan/DevBin.git\n```\n2. Install dependencies: ```bash\nnpm install\n```\n3. Configure environment variables: create a `.env` file with required variables (see Environment variables section)\n4. Run the development server: ```bash\nnpm run dev\n```\n\n## Available scripts\n| Script | Description |\n| --- | --- |\n| dev | Starts the development server |\n| build | Builds the application for production |\n| start | Starts the production server |\n\n## Project structure\n```\nDevBin/\n├── components/\n├── pages/\n├── public/\n├── styles/\n├── utils/\n├── package.json\n├── index.ts\n└── .env\n```\n\n## Environment variables\n| Variable | Required | Description |\n| --- | --- | --- |\n| DATABASE_URL | Yes | Database connection URL |\n| API_KEY | No | API key for external services |\n| PORT | No | Port number for the development server |\n\n## Contributing\nTo contribute to DevBin, please follow these steps:\n1.
