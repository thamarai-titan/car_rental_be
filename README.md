# DevBin\n\n![Build Status](https://img.shields.io/badge/build-passing-brightgreen)\n![License](https://img.shields.io/badge/license-MIT-blue)\n![Version](https://img.shields.io/badge/version-1.0.0-orange)\n\nDevBin is a curated discovery platform designed for developers to find the most trending and essential tools in the modern software ecosystem. By centralizing high-utility resources, DevBin helps developers stay ahead of the curve and optimize their workflows with community-vetted technology.\n\n## Features\n\n- **Curated Tool Discovery**: Access a hand-picked selection of trending developer utilities and libraries.\n- **Dynamic Animations**: High-performance UI transitions and motion design powered by GSAP.\n- **Type-Safe Architecture**: End-to-end type safety using TypeScript across the entire stack.\n- **Robust Data Modeling**: Efficient relational data management using Prisma ORM.\n- **Modern Web Stack**: Built on Next.js for optimized performance and SEO.\n\n## Tech stack\n\n| Layer | Technology |\n| :--- | :--- |\n| **Frontend** | React, Next.js, GSAP |\n| **Backend** | Node.js (Next.js API Routes) |\n| **Database** | SQL, Prisma ORM |\n| **Language** | TypeScript |\n| **Package Manager** | npm |\n\n## Prerequisites\n\nBefore you begin, ensure you have the following installed:\n- Node.js (v18.0.0 or higher)\n- npm (v9.0.0 or higher)\n- A running SQL database instance (PostgreSQL/MySQL)\n\n## Getting started\n\n1. **Clone the repository**\n   ```bash\n   git clone https://github.com/thamarai-titan/DevBin.git\n   cd DevBin\n   ```\n\n2. **Install dependencies**\n   ```bash\n   npm install\n   ```\n\n3. **Configure environment variables**\n   ```bash\n   cp .env.example .env\n   # Edit .env with your local database credentials\n   ```\n\n4. **Initialize the database**\n   ```bash\n   npx prisma generate\n   npx prisma db push\n   ```\n\n5. **Run the development server**\n   ```bash\n   npm run dev\n   ```\n\n## Available scripts\n\n| Script | Description |\n| :--- | :--- |\n| `npm run dev` | Starts the development server with hot-reloading |\n| `npm run build` | Compiles the application for production deployment |\n| `npm run start` | Launches the compiled production build |\n| `npm run lint` | Runs ESLint to find and fix code style issues |\n\n## Project structure\n\n```\n.\n├── prisma/             # Database schema and migrations\n├── public/             # Static assets (images, fonts)\n├── src/\n│   ├── components/     # Reusable React components\n│   ├── pages/          # Next.js routes and API endpoints\n│   ├── styles/         # Global styles and CSS modules\n│   ├── lib/            # Shared utilities and Prisma client\n│   └── types/          # TypeScript interface definitions\n├── package.json        # Project metadata and dependencies\n└── tsconfig.json       # TypeScript configuration\n```\n\n## Environment variables\n\n| Variable | Required | Description |\n| :--- | :--- | :--- |\n| `DATABASE_URL` | Yes | Connection string for your SQL database |\n| `NEXT_PUBLIC_APP_URL` | No | Base URL for the frontend application |\n| `NODE_ENV` | No | Environment mode (development/production) |\n\n## Contributing\n\nWe welcome contributions to DevBin.
